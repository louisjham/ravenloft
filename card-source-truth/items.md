# Items Source of Truth

This file contains the verbatim text transcribed from the physical Item cards. Any changes or updates should be made here first, and then propagated to the game data files.

## Items

**SILVER DAGGER**
*   **Card Type:** ITEM
*   **Trigger:** Use this item during your Hero Phase instead of attacking.
*   **Rule Text:** Attack one Werewolf within 2 tiles of you. Hit or miss, the Werewolf no longer regains Hit Points from its Regeneration ability for the rest of the game. (Attack: +5, Damage: 3, Miss: 1 Damage)
*   **Resolve Text:** Discard this card after using it.
